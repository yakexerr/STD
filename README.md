# STD
Веб-платформа для выпуска, учета и проверки подлинности дипломов и сертификатов на базе собственного блокчейн-реестра.

## Технологический стек
*   **Backend:** Node.js
*   **Frontend:** React
*   **Блокчейн-ядро:** Node.js
*   **Хранилище данных:** Гибридная модель (On-chain реестр хэшей и статусов + Off-chain СУБД для метаданных)

## Архитектура системы
В проекте используется подход **C4 Model** для многоуровневого описания системы:

* **[C4 Context (L1)](docs/architecture/C4-Context.svg)** — системный контекст, внешние акторы и границы взаимодействия.
* **[C4 Container (L2)](docs/architecture/C4-Container.svg)** — контейнеры системы (Web SPA, Backend API, База данных, Блокчейн-нода).
* **[C4 Component (L3)](docs/architecture/C4-Component.svg)** — внутренняя декомпозиция сервисов бэкенда.
* **[Архитектурные решения (ADR)](docs/adr/)** — реестр зафиксированных инженерных решений команды:
  * `ADR-0001`: Выбор стека клиентской части (React).
  * `ADR-0002`: Стратегия разделения данных (On-chain vs Off-chain).
  * `ADR-0003`: Выбор реляционной СУБД для Off-chain хранилища (MySQL).
